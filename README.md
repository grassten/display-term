# external-display-safari

An iPhone app that turns an Apple Studio Display (or any USB-C monitor) into a full-screen,
desktop-class browser driven by a Magic Keyboard and Magic Trackpad. The phone becomes the
dock and controller. Built for a single user and installed from Xcode with a free Apple ID.

**Status:** planning. See [PLAN.md](PLAN.md) for goals, verified platform constraints,
architecture, milestones, the weekly redeploy workflow, risks and open questions.
