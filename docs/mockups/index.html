Display Term — mockups (2026-10-16)

An iTerm2-style SSH terminal for the iPhone-on-a-Studio-Display setup. Terminal colours are iTerm2's Dark Background preset, the proposed default. The real panel is 3840×2160 at 1×; these frames are ~1/4.4 scale, so the font looks larger here than it will. On device the default is a 20 px Nerd Font, which gives roughly 320×80 cells across the whole display.

Tab bar on top, a title bar on every pane, a status bar at the bottom. Inactive panes are dimmed (iTerm2 default). Pane titles show user@host — cwd — command from OSC 0/7 escape codes, so they update as you cd.
